# Contributing to KensaBoss

Thanks for considering a contribution.

- Keep the interface usable in Armenian, Russian, and English when changing user-facing text.
- Preserve the study-pack format and import compatibility unless a migration is included.
- Do not commit private user data, generated APKs, signing keys, or local.properties.
- Describe the change and the Android version or device used during your review.

Small fixes and documentation improvements are welcome. For larger changes, open an issue first so the direction can be discussed.
